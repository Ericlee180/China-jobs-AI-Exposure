# 商务数据分析师

> 数据解码商机，洞察驱动增长

**职业代码**：4-07-02-05

## 职业定义

从事商务行为相关数据采集、清洗、挖掘、分析，发现问题、研判规律，形成数据分析报告并指导他人应用的人员。

## 基本信息

| 项目 | 内容 |
|------|------|
| 建设单位 | 竞争力咨询 |
| 职业等级 | 四级/中级工,三级/高级工,二级/技师,一级/高级技师 |
| 包含工种 | 贸易数据申报师 |
| 对应招聘岗位 | 数据分析专员,数据分析师,数据员,BI分析师,数据处理工程师,商业分析师,商业智能数据分析师 |
| 学历要求 | 高中毕业（或同等学力） |

## 主要工作任务

*Task Descriptions*

> 来自《职业分类大典》，对应该职业的主要工作任务，原文引用。

- 1.采集、清洗企业商务数据，建立商务数据指标体系；
- 2.分析、挖掘商务数据，产出数据模型；

- 3.撰写、制作、发布可视化数据和商务分析报告；
- 4.提供数据应用咨询服务；
- 5.分析、总结及可视化呈现业务层面数据应用情况；
- 6.监控数据指标，识别、分析业务问题与发展机会，提出解决策略。

## 评价方式

*Qualification methods*

> 来自该职业《国家职业标准》，原文引用。

- 评价分为理论知识考试、操作技能考核以及综合评审, 均实行百分制, 成绩皆达60分(含)以上者为合格。

理论知识考试以笔试、机考等方式为主, 主要考核从业人员从事本职业应掌握的基本要求和相关知识要求；
操作技能考核主要采用上机实操形式进行, 主要考核从业人员从事本职业应具备的技能水平；
综合评审主要针对二级/技师和一级/高级技师, 采用审阅申报材料、答辩等方式进行全面评议和审查。

一级/高级技师、二级/技师评价执行理论知识考试、操作技能考核和综合评审等三个考核模块, 三个模块均合格者通过评价。
三级/高级工、四级/中级工执行理论知识考试、操作技能考核等两个考核模块, 两个模块均合格者通过评价。
