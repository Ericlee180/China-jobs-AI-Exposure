# 服务机器人应用技术员

> 机器创新服务方式，科技引领美好未来

**职业代码**：4-04-05-07

## 职业定义

在家用服务、医疗服务和公共服务等领域, 从事服务机器人的集成、实施、优化、维护和管理的人员。

## 基本信息

| 项目 | 内容 |
|------|------|
| 建设单位 | 中国仪器仪表学会 |
| 职业等级 | 五级/初级工,四级/中级工,三级/高级工,二级/技师,一级/高级技师 |
| 对应招聘岗位 | 服务机器人技术服务工程师,服务机器人现场应用工程师,服务机器人售后工程师/售后维修技术员,服务机器人调试工程师,服务机器人算法工程师,服务机器人项目经理,服务机器人销售专员,服务机器人课程讲师 |
| 学历要求 | 初中毕业（或相当文化程度） |

## 主要工作任务

*Task Descriptions*

> 来自《职业分类大典》，对应该职业的主要工作任务，原文引用。

- 1.分析服务机器人在家用服务、医疗服务、公共服务等应用场景的需求，提出应用方案；
- 2.对服务机器人环境感知、运动控制、人机交互等系统进行适配、安装、调试与故障排除；
- 3.进行服务机器人应用系统的参数调测和部署实施；
- 4.对服务机器人的运行效果进行监测、分析、优化与维护；
- 5.提供服务机器人相关技术咨询和技术服务等。

*professional ability characteristics*

## 评价方式

*Qualification methods*

> 来自该职业《国家职业标准》，原文引用。

- 分为理论知识考试、 技能考核以及综合评审。 

理论知识考试以闭卷笔试、 机考等方式为主, 主要考核从业人员从事本职业应掌握的基本要求和相关知识要求; 
技能考核主要采用现场实际操作、 模拟操作等方式进行, 主要考核从业人员从事本职业应具备的技能水平; 
综合评审主要针对技师和高级技师, 通常采取审阅申报材料、答辩等方式进行全面评议和审查。

理论知识考试、 技能考核和综合评审均实行百分制, 成绩皆达60 分 (含) 以上者为合格。
