# 食品安全管理师

> 以专业守护舌尖安全，用责任筑牢食安防线

**职业代码**：4-03-02-11

## 职业定义

在食品生产、餐饮服务、食品销售等单位生产经营活动中，从事原料、食品及相关产品、人员等食品安全控制的人员。

## 基本信息

| 项目 | 内容 |
|------|------|
| 建设单位 | 山东药品食品职业学院 |
| 职业等级 | 五级/初级工,四级/中级工,三级/高级工,二级/技师,一级/高级技师 |
| 包含工种 | 冷链食品安全管理员 |
| 对应招聘岗位 | 食品质量品控员,食品安全员,食品安全总监,食品合规管理员 |
| 学历要求 | 高中毕业（或同等学力） |

## 主要工作任务

*Task Descriptions*

> 来自《职业分类大典》，对应该职业的主要工作任务，原文引用。

- 1.建立食品安全管理体系，依法制定食品安全管理制度;
- 2.申办食品生产许可证或食品经营许可证;
- 3.组织从业人员食品安全知识和相应技能培训，进行人员健康管理;
- 4.进行食品生产与经营环境的卫生管理;
- 5.进行原料、食品及相关产品的安全管理;
- 6.进行食品采购、生产、储运、销售、餐饮服务的过程管理;
- 7.进行食品安全定期自查、追溯、召回、产品留样、文件记录管理;
- 8.配合食品安全行政监管部门的食品安全监督检查和食品安全事故处理。

具备以下条件之一者，可申报四级/中级工:
（1）累计从事本职业或相关职业工作满5年。

或相关专业毕业证书(含在读应届毕业生)。
（6）取得经评估论证的高等职业学校、专科及以上普通高等学校本专业或相关专业的毕业证书(含在读应届毕业生)。

## 评价方式

*Qualification methods*

> 来自该职业《国家职业标准》，原文引用。

- 分为理论知识考试、操作技能考核以及综合评审。 

理论知识考试采用机考方式，主要考核从业人员从事本职业应掌握的基本要求和相关知识要求；
操作技能考核主要采用模拟操作的方式进行，主要考核从业人员从事本职业应具备的技能水平；
综合评审主要针对二级/技师和一级/高级技师，采取审阅申报材料、答辩等方式进行全面评议和审查。

理论知识考试、操作技能考核和综合评审均实行百分制，成绩皆达 60 分 (含) 以上者为合格。
